# PawnIO modules

Signed modules for the PawnIO driver (https://pawnio.eu), embedded in rs-cpuz and loaded
into the driver only when it is installed and the program runs as administrator.

- Source: https://github.com/namazso/PawnIO.Modules, release `0.2.12` (2026-11-17), asset `release_0_2_12.zip`
- License: LGPL-2.1-or-later (see `COPYING`); the module sources are in that repository
